## Configuration
# Root Volumes
this folders can be added as Root Volumes:
  - share
  - media
  - backup
  - addon_config
  - all_addon_configs
  - homeassistant_config
  - ssl
  - addons
  - root

share will be added as shared, because share is reserved name for Next Explorer
root - it's addon root, can be useful for dev

by default enabled share,media,backup 

# public_url
Setup your public url to enable public file sharing

# auth_mode
you can disable it for local use only. If you have public access to your ha use both or local!

See https://explorer.nxz.ai/configuration/environment.html for details
