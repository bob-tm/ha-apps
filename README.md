# Auto Repository Installation

Press the button below.

[![Open your Home Assistant instance and show the add add-on repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https://github.com/bob-tm/ha-apps)

# Manual Repository Installation

1. Navigate to add-ons page on your HA installation
2. Press three dots in the top right corner
3. Add repository `https://github.com/bob-tm/ha-apps` to addon repositories

# Apps / Add-ons
- Next Explorer App for Home Assistant (https://github.com/nxzai/NextExplorer)
- Devireg MQTT Add-on (former [https://github.com/nxzai/NextExplorer](https://github.com/bob-tm/ha-devireg-mqtt-addon))
